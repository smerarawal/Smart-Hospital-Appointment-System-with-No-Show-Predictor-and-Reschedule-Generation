Smart Scheduling

Calls Flask API with two patient probabilities → returns overbooking decision

Expected attendance formula
// For a slot with 2 bookings:
E[attendance] = P₁(show) + P₂(show) = (1 − p₁) + (1 − p₂)

// ALLOW when: both patients above threshold AND E ≤ capacity
Example: p₁=0.72, p₂=0.78 → E = 0.28 + 0.22 = 0.50 ≤ 1 ✓ SAFE
Input parameters
Patient A no-show probability0.72
Patient B no-show probability0.78
Slot capacity1
Risk threshold0.60
